## 🚀 Running the Application

- **Build Executable**
```bash
pyinstaller --noconfirm --onefile --windowed --icon "resources/logo.ico" --name "AutoRecoveryJpeg" --clean --log-level "INFO" --noupx --version-file "VERSION" "main_gui.py"
```

- **Libs**
```
pip install PyQt6 pillow
```

- **Run**
```bash
python "main_gui.py"
```
